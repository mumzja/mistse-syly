# Місце Сили

Hotseat-прототип настільної гри для 2 гравців: поселення на гексах, морські походи, духи, обереги та острови.

## Запуск

Локально — просто відкрий `index.html` (або `game.dc.html`) у браузері. Жодної збірки чи сервера не потрібно.

Через GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. Гра відкриється за адресою репозиторію.

## Структура

- `game.dc.html` — вся гра (розмітка + логіка)
- `support.js` — рантайм
- `_ds/` — дизайн-система (стилі, токени)
- `index.html` — редирект на гру
